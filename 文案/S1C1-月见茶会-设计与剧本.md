## 0. 定位

| 项 | 定 |
|---|---|
| 章节 | S1C1（全季第一章），点亮心之桥第 **1** 盏灯 |
| 灯名 | **勇气**——入席的勇气：敢坐到陌生人中间，敢说谎，敢被看见 |
| 功能 | ① 点灯 ② 全季 NPC 群像登场（茶会八席 = 后续各章常驻班底）③ 墨墨主线题眼落地 |
| 玩法 | 8 席狼人杀（简化局），玩家为关键变量，终局必做一次选择 |
| 时长 | 幕一 ~3min → 幕二 ~8-10min → 幕三 ~3min；幕二昼夜边界设存档断点 |

**两条设计原则（本章全部取舍回到这两条）**

1. **线索即人设**：每个 NPC 的言行线索（tell）直接来自他的执念与暗线——推理素材就是角色写作，不存在「为机制服务的假线索」。
2. **全分支点灯**：胜、负、中途离席，任何结局都点亮第 1 盏灯。灯量的是「她敢不敢」，不是「她赢没赢」。

## 1. 主题结构：四组镜像（你写人设时已经埋好了）

八席客人其实是四组「爱与自由」的关系对，外加一个主持。**墨墨的愿望（自由、爱）是全场的题眼，其余三对都是它的反方变奏**：

| 关系对 | 命题 | 愿望对照 |
|---|---|---|
| 千春 × 池田 | **爱 = 占有** vs 自由 = 抹除相遇 | 「留在我身边」 vs 「从未见过我」 |
| 小野 × 幸子 | **爱 = 放手** vs 爱 = 偿还 | 「她的未来要有自由的底气」 vs 「完成妈妈的一切愿望」 |
| 茶终 × 樱井 | **爱 = 庇护** vs 爱 = 背起负担 | 「樱井的烦恼消失一空」 vs 「爷爷平安，父亲回家」 |
| **墨墨 × 玩家** | 自由 **×** 爱，两个都要 | 不是把谁留在身边，也不是独自出走——**「和他一起走出去」** |

- 千春是墨墨的**暗面镜像**：一个把所爱之人关进洋娃娃屋子的女孩。墨墨是什么，如果没有人陪她走出小岛的话。
- 全章的情绪收口 = 幕三茶终人散时，千春对墨墨的一问，墨墨的一答（§4 幕三 / §10 配音位②）。
- 这一段同时是整个游戏结局路线 C（「一起出走」）的第一次预演。

## 2. 角色配置总表（8 席 + 主持）

> 立绘命名与现有表情词表完全一致（不悦/低头落寞/害羞/悲伤/惊讶/欲言又止/眯眼笑/默认），引擎零改造接入。

| 角色 | 身份 | 人格标签 | 行为线索（tell，全部来自执念） | 夜茶刀口 / 投票倾向 | 立绘源 |
|---|---|---|---|---|---|
| 千春 | **隐狐** | 软萌腹黑·病娇 | 被指认时**先笑后哭**；发言永远黏着池田席 | **永不点池田的夜茶**；被票时哭护池田 | `月见茶会- NPC/千春妹妹` |
| 茶终 | **隐狐** | 寡言大家长·惜字如金 | 每句话 ≤10 字；**票永远护樱井**（玩家可读出的行为线） | **永不点樱井的夜茶**；弃票率高 | `月见茶会- NPC/茶终爷爷` |
| 墨墨 | **隐狐**（玩家同伴） | 傲娇毒舌·逻辑流 | 悍跳照镜；发言里对玩家**多一句关心**（§3 tell 定义） | **永不点玩家的夜茶**；票护玩家 | 现有立绘（按存档服装） |
| 樱井 | **照镜**（真预言家） | 理性克制·条理清晰 | 报查验必带**精确编号**；用语公理化 | 每夜验沉默位优先（首夜验幸子） | `月见茶会- NPC/樱井小姐` |
| 小野 | **药茶**（女巫） | 乐观好胜·外刚内柔 | **幸子被点夜茶必救**（身份泄露点，就是她的执念） | 首夜救人概率高；毒茶只给「威胁幸子的人」 | `月见茶会- NPC/小野女士` |
| 幸子 | 客（平民） | 疲惫优等生·不敢带队 | 发现漏洞**只说半句**；弃票/跟随票 | 第二日才敢第一次坚定发言（脚本化成长节拍） | `月见茶会- NPC/幸子小姐` |
| 池田 | 客（平民） | 冲动易怒·被害妄想 | 发言乱指，**死咬千春**（执念泄露的噪音位） | 直觉投票，被千春发言严重干扰 | `月见茶会- NPC/池田先生` |
| **玩家** | **末茶**（猎人） | 局内关键变量 | ——（玩家的 tell 就是玩家自己） | 发言卡 + 投票 + **终局递茶** | POV |
| 月见 | **主持**（不入局） | 银狐面具正太·博弈爱好者 | 判定真假、实现愿望 | 不入局 | `月见茶会- NPC/月见`（已到位，8 表情；以「疑惑」替代「悲伤」——博弈者不悲伤，成立） |

**三个隐狐，为什么平衡反而成立**：刀口被执念锁死——千春不碰池田、茶终不碰樱井、墨墨不碰玩家。三把刀天然偏软，加上千春哭票、茶终护票、池田乱指带来的好人侧噪音，实际强度 ≈1.5 狐对 5 客。**平衡的理由长在人物关系里，不需要数值硬调。**

## 3. 局内规则：「茶礼制式」（狼人杀的换皮）

> 原版狼人杀的「放逐/刀人」字眼与「毒舌但温馨」的基调冲突。全部术语换成茶礼，气质统一，且与月见·狐的传说咬合。

| 原术语 | 茶礼制式 | 说明 |
|---|---|---|
| 狼人 | **隐狐** | 月见茶会传说：十五夜，狐混进茶会，学人喝茶，学人许愿 |
| 夜刀 | **夜茶** | 夜里被隐狐请去喝一杯苦茶，次日离席 |
| 放逐投票 | **请离席** | 得票过半者离席，茶盏收走 |
| 预言家查验 | **照镜** | 对镜看人心：狐是人非，一照便知 |
| 女巫救/毒 | **药茶** | 一盏回魂茶 + 一盏断念茶，各限一次 |
| 猎人开枪 | **末茶** | **终局由末茶人递出最后一杯茶**——玩家必做选择 |
| 真假预言家对跳 | **双镜对峙** | 墨墨悍跳 vs 樱井，全章核心谜面 |

**流程（单夜循环 ×2，总 8-10 分钟）**

```
幕一 入席（剧本）→ 第一夜（闭目演出）→ 第一日：双镜对峙 + 发言轮 + 请离席
   → 第二夜 → 第二日发言 → 终局判定 → 末茶递茶（玩家）→ 幕三 结算（剧本）
```

- 第一夜目标由刀法约束表加权抽取（§2）；照镜/药茶为 AI 决策，玩家闭目观看演出（猎人无夜职，夜相短）。
- 昼间每人一段发言（池抽取，§7），玩家以**发言卡**行动（§6），随后投票。
- 判定：狐数 ≥ 客数则狐胜；狐清零则客胜；最多两个昼日，超时进入终局递茶强制结算。
- 断点存档：昼→夜边界各存一次（沿用现有存档点架构），三幕不必一口气吃完。

**墨墨的 tell（本章谜底机制）——「看穿她不靠逻辑，靠认识她」**

1. **多一句**：她的悍跳发言末尾，会出现一句照镜不该说的话——「……你，别乱投票。跟着我走就行。」（对玩家的关心泄露）
2. **表情线**：千春看向池田时，墨墨立绘有一个瞬间的欲言又止（只有好感 ≥ Lv5 的老玩家会注意到她在走神）。
3. **行为线**：她的票永远不落玩家头上（狐护猎，行为不合理）。

三条 tell 全部指向同一个事实：**她在保护你**。玩家能否看穿，取决于玩家有多认识她——数月的日常交互（状态感知台词/好感分层）就是这一刻的伏题。

## 4. 三幕流程

### 幕一 · 入席（~3min，纯剧本，director 节点）

场景：`茶歇间-夜晚`（备选 `仪式间-夜晚`）。节点序列（照 `dialogues.json`「脚本」桶现有格式）：

```json
{
 "id": "ch1_入席",
 "flag": "story.ch1_seated",
 "nodes": [
  { "type": "narration", "text": "十五夜。月亮圆得不像话，洋馆的茶歇间第一次坐满了人。" },
  { "type": "narration", "text": "上座摆着一只银狐面具。面具后面，是一个白发的孩子。" },
  { "type": "say", "who": "月见", "text": "欢迎。我是今晚的主人，月见。" },
  { "type": "say", "who": "月见", "text": "规矩只有一条：茶会八席，三席是狐。找出它们——或者，别被找到。" },
  { "type": "say", "who": "月见", "text": "赢下茶会的一方，愿望会被听见。那么，先请诸位说说自己的愿望。" },
  { "type": "stage", "who": "千春", "text": "……池田哥哥，来年也、永远，都坐在我身边喝杯茶吧？" },
  { "type": "stage", "who": "茶终", "text": "……樱井的烦恼，消失一空。" },
  { "type": "stage", "who": "小野", "text": "幸子的未来，要有说『不』的底气——不像我。" },
  { "type": "stage", "who": "幸子", "text": "妈妈的愿望……由我全部完成。就这样。" },
  { "type": "stage", "who": "池田", "text": "回到从前。父母健在，千春……从未见过我。" },
  { "type": "say", "who": "月见", "text": "客人，你的愿望呢？" },
  { "type": "choice", "options": [
    { "label": "希望墨墨一直开心", "say": "希望墨墨，一直这样开心。", "apply": { "story.wish": "happy" } },
    { "label": "想陪她走更远",     "say": "想陪她……走更远一点。",   "apply": { "story.wish": "far" } },
    { "label": "……说不出口",      "say": "……这个愿望，说不出口。",  "apply": { "story.wish": "secret" } }
  ]},
  { "type": "expr", "name": "欲言又止", "hold": 1200 },
  { "type": "say", "text": "……轮到我了吗。" },
  { "type": "say", "text": "我的愿望——以后再告诉你们。" },

```

> 玩家的愿望存 `story.wish`，幕三由月见复述回给玩家（三个分支各不同回声）。墨墨的愿望故意留白——因为她的愿望（自由×爱）月见实现不了（§5）。

### 幕二 · 对局（~8-10min，`party.js` 状态机）

- 逐阶段状态机：`入席演出 → 夜1 → 昼1（双镜对峙/发言/票）→ 夜2 → 昼2 → 终局递茶`。
- 每阶段：NPC 立绘上桌（stage 槽位）+ 发言池抽取 + 玩家发言卡交互；昼间发言出对话气泡，复用 director 的 say 渲染。
- 关键脚本节拍（固定，不随机）：
  - **D1 双镜对峙**：樱井起手报精确编号验人 → 墨墨后手悍跳，tell①「多一句」落在这里。
  - **D2 幸子的第一次**：无论局面如何，幸子在第二日说出全场唯一一句坚定发言（§7 样例）——她是「不敢开口的发言者」的镜像，也是这章写给玩家的语用示范。
  - **终局递茶**：月见宣布判定前，先请末茶人（玩家）递出最后一杯茶——**点谁，谁的愿望被听见**。这是玩家的「最终选择」。

### 幕三 · 结算（~3min，分支剧本）

先演终局递茶的后果，再演愿望兑现，最后收在题眼问答与点灯：

```
月见兑现胜方推举的一个愿望（客胜 → 众人推举茶终的愿望，给樱井的；狐胜 → 千春抢下这杯……）
→ 千春离席时，在墨墨耳边的一问：「小墨墨，你不想把那个人……永远留在身边吗？」
→ 墨墨的答（题眼，配音位②）：「……我想要的，从来不是把谁留在身边。」
                                    「是和他一起，走出去。」
→ 月见（低声）：「自由不是愿望，是脚步。小墨墨，去吧。」
→ 场景切 鸟居-夜晚 / 大地图心之桥头 → 第一盏灯，亮了。
```

## 5. 分支矩阵（全分支点灯）

| 线 | 触发 | 幕三演出核心 | 数值 |
|---|---|---|---|
| **A 被看见** | 末茶递给墨墨 / 投出决定性的一票 | 她摘下「悍跳面具」：第一次被人看穿，也是第一次被人看见。好感大加。 | 好感 +20，货币 +80 |
| **B 同行** | 全程信她，狐胜 | 她赢了茶会，却在愿望环节安静下来——月见实现不了她的愿望。低声复述幕一玩家的愿望。 | 好感 +15，货币 +80 |
| **C 护座** | 玩家中途离席（夜茶/被票） | 她替你打完剩下的一日。护着你的空茶杯发言。结算时复杂表情。 | 好感 +12，货币 +80 |

- **灯 1 无论如何点亮**：灯量的是「她敢坐上这桌」。
- 月见实现愿望的规则：只实现**胜方推举的一愿**，且是「听见」而非「改写」——千春的愿望被听见（池田沉默着收下了茶），但月见给的是契机不是结果。苦甜味，不做恐怖向。
- **墨墨的愿望月见无法实现**：这条是灯存在的理由——她的愿望不在茶里，在桥上。第一章末，月见说破这一点。

## 6. 语言学习层（机制即语用训练）

- **发言卡 = 玩家的行动**，每张卡是一种语用策略，随 `immersiveLevel` 抬高目标语浓度：

| 卡 | 中文表述 | 目标语层（1 档示例） |
|---|---|---|
| 委婉质疑 | 「总觉得……刚才那句话有点怪」 | "I'm not sure, but something felt off…" / 「なんだか……さっきの言葉、少し変でした」 |
| 直接指认 | 「我认为隐狐是她」 | "I think the fox is her." / 「狐は、彼女だと思います」 |
| 沉默观察 | （不出声，盯视一人 → 读取其反应） | ——（行为卡，无台词） |
| 声援 | 「我相信你」 | "I believe you." / 「信じます」 |

- **章节词包「十五夜」**（tags: `["s1c1"]`，进 SRS，茶会内浮标即点即学）：
  - JA：月見・十五夜・団子・願い事・狐・神様・鳥居・灯り・橋・自由・勇気・嘘
  - EN：moon-viewing / harvest moon / wish / fox / shrine / lantern / bridge / freedom / courage / lie / tea / vote
- 全员和风日语名 + 照镜/药茶术语 → JA 轨浓度天然成立；EN 轨走双语字幕卡。
- 幸子线 = **害羞发言者**的镜像：第二日她的第一次坚定发言就是给玩家的示范——语言学习的高阶目标从来不是词汇量，是敢开口。

## 7. 发言池 schema 与风格样例（口味样张，定稿后照此批量扩写）

```json

  "tells":  { "…": "§3 三条 tell 的触发条件" }

```

风格样例（每角色 2~3 条，供你校口味）：

- **千春**「大家围在一起喝茶，真好呢。……对吧，池田哥哥？」／被指认：「诶？我是隐狐？……人家、会哭的哦？」（先笑，后哭）
- **茶终**「怀疑她，先给理由。」／投票时：「……樱井说得对。」（惜字如金，每句 ≤10 字）
- **樱井**「昨夜，我看的是三号位。结论——清白。」／对跳：「同一面镜子，照不出两个持镜人。」
- **小野**「直觉！今天这桌上的坏水，就数他笑得最甜。」／救幸子后：「……幸子，谁都不许碰。」
- **幸子** D1：「逻辑上有一个漏洞。但……可能是我多想了。抱歉。」→ D2 坚定节拍：「不对。请听我说完——**这一次，我确定。**」
- **池田**「别、别用那种眼神看我！……千春你别看我了！！」
- **月见** 开场：「十五夜，月最圆的一夜。狐最爱这种日子——混进茶会，学人喝茶，学人许愿。今晚八席，三席是狐。」／递茶：「终局之茶，由末茶人递出。递给谁，谁的愿望就被听见。」
- **墨墨** 悍跳（配音位①）：「……先说结论。我是照镜。信不信随你们——反正，镜子不说谎。」／tell①：「……你，别乱投票。跟着我走就行。」／A 线揭面（配音位③）：「哼……看穿了啊。真好啊，被你看穿。」

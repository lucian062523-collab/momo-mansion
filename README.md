# 墨墨的洋馆 / Momo's Mansion

一个带桌面宠物与 AI 角色茶会的单机文字冒险。

- 桌宠墨墨：陪伴、吐槽、学习记录
- 第一章「月见茶会」：八席、随机身份、AI 角色自演狼人杀
- 个人语料库：本地、按用户隔离的检索与对照

## 仓库说明

本仓库是可公开的**源码与文案**，不包含：

- `dist/` 构建产物与线上包
- `墨墨上线包.zip` / `发布/` 安装包
- 约 500MB 的美术资产（CG、立绘、场景），因为体积超过普通 Git 仓库限制
- `worker/.dev.vars` 等密钥文件

游戏在线版：https://mymomo.pages.dev

## 目录

```
game/content/   剧情、角色、场景、茶会配置
game/js/        游戏逻辑、AI 茶会、语料库
_tools/         构建与校验脚本
worker/          AI 代理（Cloudflare Worker，密钥不入库）
文案/           剧情与文本
评测/           评测报告
```

## 本地运行

需要美术资产与构建环境；将资产目录放回后运行：

```bash
bash _tools/build_locked.sh
```

构建产物在 `dist/`。

## 说明

本项目为 Game Jam 作品，仍在迭代。AI 茶会需要网络；离线时角色会降级为本地台词库。
